Poll a command session returned by run_terminal. Pass {"session_id":"..."}; optional yield_time_ms waits 0–30000 ms for output or exit. Running output is incremental and bounded, retaining its beginning and end. A running result is not a completed command. Keep the same session_id; never restart a command just because a wait elapsed. Set terminate=true to cancel this command and its process tree. Sessions belong to this conversation and workspace and expire after 30 minutes without polling. Polling does not require another approval for the already authorized command.
