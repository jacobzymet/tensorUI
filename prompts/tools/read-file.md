Read a bounded page of a UTF-8 file, regardless of the file's total size. Pass {"path": "relative/or/absolute"}. Optional offset is a 0-based line number; limit defaults to 200 lines (maximum 2000). max_bytes limits the page to 256–32000 bytes. To continue, use the exact byte_offset printed in the response, without offset; this also handles long single lines. Only text after "--- file content ---" is file content. The response explicitly says when it reaches the end of the file.
