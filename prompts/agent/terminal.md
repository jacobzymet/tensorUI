run_terminal executes one command in the workspace (timeout {{timeout}}s). {{shell_context}} Use it for builds, tests, and git only when the user's instructions permit them — not for reading or writing files. Use read_file with offset/limit for file excerpts. Commands are reviewed before they run. Do not request privilege escalation, disk wipes, or piping downloads into a shell. A nonzero exit or timeout is a failure: inspect the output and fix the cause before claiming success.
