    Approvals

    Applies to every capability below. File writes and terminal commands always need your OK, even when auto-approving safe actions.

    Safe actions: web search, fetch URL, and reading files. Default is to ask every time.

    Web search

    Parallel and TinyFish need an API key only for higher limits / TinyFish auth. Parallel works free via Search MCP with no key. SearXNG needs an instance URL.

    Optional. Leave blank to use Parallel’s free Search MCP. A key (or PARALLEL_API_KEY) unlocks higher limits and mode controls via the REST API.

    Used when an API key is set (REST). Free MCP mode ignores this and uses Parallel’s default basic preset.

    Free Search API via TinyFish / Monid. Get a key at agent.tinyfish.ai, or set TINYFISH_API_KEY. Leave blank to use the env var.

    Required for the SearXNG provider. In Auto mode, this instance is tried first (JSON if enabled, otherwise HTML) and DuckDuckGo is used if it fails. Local instances such as http://127.0.0.1:8080 are allowed.

    How many linked results to return to the model (1–20).

    A DDGS region code such as us-en, uk-en, or wt-wt for worldwide.

    Search returns titles, URLs, and snippets. Use fetch_url to read a specific page. Depth optionally prefetches result pages during the search itself.

    Caps text from each page opened by web search page depth. Use 0 for each depth’s default (auto 2800, light 1600, standard 3200, deep 4800).

    Fetch URL

    Max characters returned per chunk (~8,000 recommended). The model uses pagination offsets to read longer pages.

      Attachments

      File uploads in chat. By default the paperclip follows whether the selected model reports vision / multimodal support.

      Availability

      Auto grays out the paperclip when the model has no vision metadata. Open this pane to force-enable or turn on text extraction.

      Text extraction fallback

      Off by default. When on, PDFs and text files are parsed into markdown-ish text and sent in an Attachment: block. Useful for models without native file support, when the context window is large enough.

      Text fallback stays off unless the model’s reported context is at least 16k tokens (or unknown). Oversized extracts are truncated.
