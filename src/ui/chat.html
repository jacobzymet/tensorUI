    Attachments

    File uploads in chat. By default the paperclip follows whether the selected model reports vision / multimodal support.

    Availability

    Auto grays out the paperclip when the model has no vision metadata. Open this pane to force-enable or turn on text extraction.

    Text extraction fallback

    Off by default. When on, PDFs and text files are parsed into markdown-ish text and sent in an Attachment: block. Useful for models without native file support, when the context window is large enough.

    Text fallback stays off unless the model’s reported context is at least 16k tokens (or unknown). Oversized extracts are truncated.
